# Python implementation of the Actuarial Climate Index

This repository contains a Python port of the [`rIACI`](https://cran.r-project.org/package=rIACI) R package and a workflow for calculating an Actuarial Climate Index for the Pomerania region.

## Repository contents

- `python_iaci/` contains the Python package and its functions.
- `lectures/` contains the source presentation materials.
- `pomeranian_aci_workflow.ipynb` contains the complete calculation of the Pomeranian Actuarial Climate Index.
